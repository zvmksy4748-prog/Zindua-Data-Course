**Python Programming**

Learn how to code with the Python programming language. You'll go from the basics or programming and Python syntax to advanced Python concepts allowing you to build robust scripts and programs.

**Course Overview**

In this course, you'll learn the end-to-end fundamentals of the Python programming language. By the end of the course, you should be able to build advanced and functional Python scripts, scrape the web, call APIs, and even interact with databases with the Python programming language. The course is broken down into the following modules as follows:

_**Python Foundations**_: Understand Python syntax and how to build your first scripts i.e. variables & constants, conditionals, functions, loops, and basic conventions

**_Python Data Types_**: Learn about different data types in Python and explore their unique methods i.e. strings, files, lists, tuples, dictionaries, and sets

**_Using Web Services_**: Scrape the web and access data from APIs using regular expressions as well as libraries like Requests and Beautiful Soup

**_Advanced Python_**: Delve into object-oriented programming, test-driven development, working with databases, and advanced conventions

**_Course Capstone_**: Build an end-to-end Python script
